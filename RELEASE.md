# StarLight Legacy Release 0.1.0

This is the root-level release file for the current **Legacy Fabric 1.12.2** build.

## Target
- Minecraft `1.12.2`
- Loader `legacy-fabric-loader`
- Environment `client`
- Mod ID `starlightlegacy`

## Expected artifact
- `starlight-legacy-0.1.0.jar`

## Install
1. Install Legacy Fabric Loader for Minecraft 1.12.2.
2. Put `starlight-legacy-0.1.0.jar` into your `mods/` folder.
3. Start the game once to generate `config/starlightlegacy.properties`.
4. Edit `max_fps` and `view_distance` if you want different tuning.

## Notes
- This release is only for **Legacy Fabric 1.12.2**.
- Versioned release notes remain in `releases/0.1.0.md`.
