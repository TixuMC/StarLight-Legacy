# StarLight Legacy 0.1.0

## Release target
- Minecraft `1.12.2`
- Loader `legacy-fabric-loader`
- Environment `client`

## Included behavior
- Applies FPS-friendly client defaults on startup.
- Supports config overrides through `config/starlightlegacy.properties`.
- Saves updated options when the underlying client exposes a matching save method.

## Expected mod artifact
- File name: `starlight-legacy-0.1.0.jar`
- Mod ID: `starlightlegacy`

## Install
1. Install Legacy Fabric Loader for Minecraft 1.12.2.
2. Place `starlight-legacy-0.1.0.jar` in your `mods/` folder.
3. Launch the game once to generate `config/starlightlegacy.properties`.
4. Adjust `max_fps` and `view_distance` if desired.

## Notes
This release is intended specifically for **Legacy Fabric 1.12.2** and should not be used with modern Fabric Loader branches.
